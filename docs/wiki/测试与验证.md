## 一键离线安装验收

`scripts/verify_offline_install.ps1` 把安装验收收敛为一条命令（见 [安装与部署](安装与部署.md)），按顺序检查 9 步：

1. 安装包存在性与 SHA256；
2. 干净机前置条件（`PATH` 上无 `python`/`python3`/`py`）；
3. 桌面快捷方式未被占用；
4. 静默安装（独立临时目录）；
5. 安装后 EXE 与 `dist\SecOne\SecOne.exe` 哈希一致；
6. 卸载注册项；
7. 快捷方式 `TARGET`/`WORKDIR` 解析；
8. 经快捷方式、最小 `PATH`、无 Python 环境启动并检查首启产物（`history.db`、`-wal`、`-shm`、`secone.log`）；
9. 静默卸载并确认程序文件/快捷方式/注册项移除，`data\`、`logs\` 保留。

任一步失败即非零退出，并写出 `artifacts/offline_install_report.json`。`-CleanMachine` 只在报告 `scope` 字段记录“由操作者声明为干净机”，脚本本身无法证明机器干净——本机自检 9/9 已通过，**干净机验收当前仍为 BLOCKED**（无干净测试机）。

## 验证边界

- 模拟 llama-server 只用于协议与错误路径回归；LFM2 架构、对话模板与真实生成已由实机验收覆盖，但那只证明链路可用，不构成生成质量或解题准确率结论（见 [基准与评估](基准与评估.md)）。
- UI 交互测试在 offscreen Qt 下使用信号级 `StubWorker`；真实鼠标拖拽、真实多显示器与系统级缩放观感仍需人工验收。
