# 安装与部署

SecOne 的运行不依赖系统 Python，也不依赖互联网；模型权重和 llama.cpp 运行组件作为独立资源包分发。完整交付物清单见 [docs/OFFLINE_INSTALL.md](https://github.com/wakawakalululu/SecOne/blob/main/docs/OFFLINE_INSTALL.md)。

## 开发模式（从源码运行）

要求：Windows 10/11 x64，Python 3.11–3.13（项目使用 3.12）。

```powershell
python -m venv .python
.\.python\Scripts\activate
pip install -r requirements.txt
python run_secone.py
```

首次启动会创建 `data/`、`workspace/`、`output/`、`logs/`，并读取 `config/app.yaml`。

## 交付物形态

| 文件 | 说明 |
| --- | --- |
| `SecOne-1.0.0-rc1-portable-win64.zip` | 便携包（推荐）：解压即运行，含 Nuitka standalone 程序、Qt 运行时与 `python312.dll`（约 113 MB） |
| `SecOne-1.0.0-rc1-setup.exe` | Inno Setup 6.7.4 安装包：当前用户安装到 `%LOCALAPPDATA%\Programs\SecOne`，无需管理员权限 |
| `SecOne-model-*.zip` | 模型资源包：GGUF、`model.json`、可选 `runtime/`、许可文件与 `SHA256SUMS.txt` |
| `SHA256SUMS` | 发布物整体校验清单（141 条，含 138 个程序文件） |

主程序包不含模型权重与 llama.cpp 二进制；缺少模型时静态分析仍完整可用。

## 安装主程序

**便携 ZIP**：`certutil -hashfile <zip> SHA256` 对照清单 → 解压到任意可写目录（如 `D:\SecOne`）→ 运行 `SecOne.exe`。首次启动在程序目录下创建 `data/`、`workspace/`、`output/`、`logs/`。

**安装包**：校验 SHA256 → 双击安装（默认 `%LOCALAPPDATA%\Programs\SecOne`）→ 从开始菜单启动。卸载不会删除 `models/`、`runtime/`、`data/`、`workspace/`、`output/`、`logs/`。

## 安装模型与推理引擎

1. 校验模型包 SHA256，解压后把 `models/`、`runtime/`、`licenses/` 合并到程序目录：
   ```text
   <SecOne 程序目录>\models\XuanmuSec-v2-Q6_K.gguf
   <SecOne 程序目录>\runtime\llama-server.exe
   ```
2. 启动 SecOne，进入“模型与设置”：
   - 确认模型状态（GGUF magic/version 校验、对话模板存在）；
   - 文件名与默认值不一致时，点“扫描 models/ 中的 GGUF”直接选用；
   - 点“启动本地引擎”，健康检查通过后点“测试连接”。

模型路径、运行时路径、端口（默认 `18080`）、上下文、GPU 层数与线程数都在设置页修改，无需重新编译。

模型服务只监听 `127.0.0.1`，接口为 `GET /health`、`GET /v1/models`、`POST /v1/chat/completions`。

## 候选模型与下载选项

设置页“模型资源”区提供**候选模型**下拉框，数据来自 `models/candidates.json`（可自行增删条目）。选中条目显示架构、建议上下文、说明与获取渠道，并提供“打开下载页”（系统浏览器）与“复制链接”按钮。**程序自身不联网下载**（离线优先）：从发布页获取 GGUF 放入 `models/`，再点“扫描 models/ 中的 GGUF”选用。

内置候选（截至 v1.0.0-rc1）：

| 模型 | 规模 | 说明 |
| --- | --- | --- |
| XuanmuSec-2.6B `Q6_K` | 约 2.07 GiB | 默认模型，安全领域微调，已完成 RC1 实机链路验证 |
| Qwen2.5-0.5B-Instruct `q4_k_m` | 约 469 MB | 超轻量，低配机器可跑，RC1 验证同款 |
| Qwen3-0.6B | 约 0.5–0.8 GB | Qwen3 系列最小稠密模型，超轻量候选 |
| Qwen3.6-35B-A3B | 35B MoE（激活约 3B） | 2026-04 发布，Apache 2.0，稀疏 MoE 适合家用显卡；需 llama.cpp b8809+ |
| Qwen3.8-27B | 27B 稠密 | 2026-08 开源的原生多模态稠密模型，Apache 2.0 |

- Qwen3.6-35B-A3B 的 GGUF：[unsloth/Qwen3.6-35B-A3B-GGUF](https://www.modelscope.cn/models/unsloth/Qwen3.6-35B-A3B-GGUF)（ModelScope）
- Qwen3.8-27B：[Qwen/Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B)（Hugging Face 官方）、[lmstudio-community/Qwen3.8-27B-GGUF](https://huggingface.co/lmstudio-community/Qwen3.8-27B-GGUF)（GGUF）

更换任何模型都不需要改动业务代码：GGUF 架构由元数据动态识别（`general.architecture`），模型加载与对话模板以实际权重为准；不同 llama.cpp 版本对 Qwen3.6/3.8 等新架构有最低版本要求（如 Qwen3.6 需 b8809+），放入 `runtime/` 后建议先在设置页“启动本地引擎 + 测试连接”验证。

## 一键离线验收

干净 Windows 机器上执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify_offline_install.ps1 -CleanMachine

# 需要同时验收模型包时：
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify_offline_install.ps1 -CleanMachine `
  -ModelPackage dist\packages\SecOne-model-XuanmuSec-2.6B-Q6_K.zip
```

脚本覆盖安装 → 快捷方式 → 最小 PATH 无 Python 启动 → 首启产物 → 可选模型包部署 → 静默卸载共 9 步，任一步失败非零退出，并写出 `artifacts/offline_install_report.json`。详见 [测试与验证](测试与验证.md)。

## 部署排障

| 现象 | 处理 |
| --- | --- |
| 模型状态“缺少对话模板” | GGUF 元数据缺 `tokenizer.chat_template`，换用模型发布方完整版本 |
| 模型状态“尚未完成实机推理验证” | 文件头有效但本会话未成功调用推理；启动引擎并测试连接 |
| 端口被占用 | 设置页更换端口（默认 `18080`） |
| llama-server 提前退出 | 查看 `logs/llama-server.log`，确认运行组件版本与 GGUF 架构匹配 |
| 杀毒软件拦截 | Nuitka 产物可能被启发式误报，核对发布清单 SHA256 后再放行 |
