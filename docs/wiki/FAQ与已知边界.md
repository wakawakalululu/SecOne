# FAQ 与已知边界

## 安全与隐私

**SecOne 会联网吗？**
不会。程序默认不联网、不上传材料；所有推理通过本机 `127.0.0.1:18080` 的 llama.cpp OpenAI 兼容接口完成。程序不自动扫描公网、不发起外部网络探测、不执行用户提供的未知二进制。

**模型输出会被自动执行吗？**
不会。模型输出只作为分析建议，当前版本没有开放任意工具调用，也不会自动执行模型生成的 Shell 命令。模型提出的 Flag 必须逐字出现在材料或证据中才会保留为 `candidate`，且始终需要人工确认。

**`verified` 状态什么时候出现？**
`verified` 预留给后续验证器/人工确认流程；当前版本不会自动把候选升级为已验证。

## 安装与运行

**没有模型能用吗？**
能。文件摄入、安全解包、静态分析、Flag 引擎和报告导出不依赖模型；界面会显示“模型未安装”与缺失明细，AI 页签只显示跳过原因。

**模型状态显示“缺少对话模板”？**
GGUF 元数据里没有 `tokenizer.chat_template`。请换用模型发布方提供的完整版本。

**模型状态显示“尚未完成实机推理验证”？**
文件头有效但本次会话尚未成功调用推理服务；启动本地引擎并通过健康检查、点“测试连接”后才会显示在线。

**端口 18080 被占用？**
在“模型与设置”页更换端口即可，配置写回 `config/app.yaml`，无需重新编译。

**llama-server 提前退出？**
查看 `logs/llama-server.log`，确认运行组件版本与 GGUF 架构匹配（不同 llama.cpp 版本参数可能存在差异，升级运行组件后请用实际模型做一次启动与推理验证）。

**杀毒软件拦截 SecOne.exe？**
Nuitka 打包产物可能被启发式误报。请先核对发布清单中的 SHA256，确认一致后再决定是否放行。

**RAR 压缩包为什么解不了？**
RAR 解压依赖外部组件，第一版只保留原文件并给出提示。

**卸载/升级会丢任务数据吗？**
不会。任务库、工作区、证据与报告位于 `data/`、`workspace/`、`output/`，安装包将这些目录标记为卸载不删除；升级主程序不触碰 `models/` 与 `runtime/`。

## 设计定位

SecOne 的价值主张是**可追溯**：每个 Flag 候选保留来源、偏移、解码链、证据和置信度；确定性引擎负责机械还原，模型只提供线索。因此“模型答不出来”不影响核心工作流，而“模型答出来的内容”必须回到证据中逐字命中才能进入候选列表。
