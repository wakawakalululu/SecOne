# 架构说明

## 项目结构

```text
config/               运行时配置（app.yaml）与提示词（prompts.yaml）
models/               GGUF 放置目录与模型清单（model.json）
runtime/              llama-server 放置目录
assets/               图标资源
src/secone/
  config.py           配置合并与保存
  paths.py            应用根目录、工作区与日志路径
  db.py               SQLite WAL 任务库
  domain.py           领域模型
  core/
    ingest.py         材料接入、安全解包、索引
    classify.py       题型与文件分类
    fileio.py         指纹、编码、文本与字符串
    flag_engine.py    Flag 规则、解码、防幻觉
    workspace.py      任务工作区布局
    report.py         报告生成
    pipeline.py       分析流水线
    plugins/          Crypto / Forensics / Web / Binary / Misc
  llm/
    server.py         llama-server 进程生命周期管理
    client.py         OpenAI 兼容客户端（含取消中断）
  ui/                 PySide6 界面、主题、工作线程与页面
scripts/              开发预览、验证与打包辅助脚本
packaging/            Nuitka 与 Inno Setup 打包配置
docs/                 发布说明、测试报告与离线安装文档
tests/                pytest 测试
benchmarks/           标准答案语料（ctf_accuracy_v1–v4）
```

## 分析流水线

```text
材料接入（ingest）
  ├─ 复制到 workspace/<task_id>/input/
  ├─ 安全解包（递归、限深、防路径穿越）→ extracted/
  └─ SHA256 指纹去重 → 材料清单
分类（classify）
  └─ 题型倾向与文件类型（Magic/扩展名/结构）
插件分析（core/plugins/）
  ├─ crypto     编码/古典密码/XOR/RSA 线索
  ├─ forensics  元数据/容器结构/字符串/熵
  ├─ web_audit  危险调用与注入规则
  ├─ binary     PE/ELF 静态结构（不运行样本）
  └─ misc       综合检查
Flag 引擎（flag_engine）
  ├─ 规则匹配 found
  ├─ 确定性解码 → candidate（含证据回查）
  └─ 占位符过滤、跨来源去重
本地 AI（可选，llm/）
  ├─ GGUF 头校验 → 启动 llama-server → /health
  ├─ 结构化提示词（prompts.yaml）
  └─ 输出逐字回查证据后才进入候选
报告与落库（report / db）
  └─ report.md/.txt/.json + SQLite 任务历史
```

## 关键设计

- **证据优先**：所有 Flag 候选保留来源、偏移、解码链与证据原文；AI 输出必须逐字命中材料或证据才保留，且始终为 `candidate`。产品价值主要来自可追溯的解码与证据回查，而不是模型直接给出答案（见 [基准与评估](基准与评估.md)）。
- **模型可插拔**：模型、运行组件和参数全部来自本地配置文件（`config/app.yaml` + `models/model.json`），替换资源不需要修改业务代码；界面设置页可改路径、端口、上下文、GPU 层数与线程数。
- **默认离线**：推理只走 `127.0.0.1:18080` 的 OpenAI 兼容接口；无模型时流水线跳过 AI 阶段并在结果中注明原因，静态分析不受影响。
- **协作式取消**：流水线以 `threading.Event` 检查取消，模型请求等待可被中断；取消后任务在 SQLite 落库为 `cancelled`。
- **安全解包**：限制嵌套深度、条目数量、展开体积与单文件体积，拒绝路径穿越、绝对路径和符号链接，处理加密压缩包与不支持的格式。

## 配置与提示词

- `config/app.yaml`：应用信息、引擎参数（模型路径、端口、上下文、温度、GPU 层数、超时）、分析限制、Flag 正则与自定义前缀、UI 主题、路径。界面修改后写回该文件。
- `config/prompts.yaml`：系统提示词与用户模板。系统提示词带硬性规则（不得编造内容/偏移/flag、证据不足要明说、疑似 flag 逐字引用、不提供公网攻击步骤）；用户模板注入分析模式、材料清单、静态发现、已提取候选与材料摘录。
